개인정보처리방침

이 사이트가 처리하는 정보와 이용 중인 제3자 서비스 안내

이 사이트(https://baba9811.github.io, 이하 “사이트”)는 논문 리뷰와 연구 노트를 게시하는 개인 블로그입니다. 아래는 사이트를 이용할 때 어떤 정보가 어디로 전달되는지에 대한 안내입니다.

1. 운영자가 직접 수집하는 정보

없습니다. 사이트는 서버 측 로직이 없는 정적 웹사이트로, 회원 가입·로그인·댓글·문의 양식이 존재하지 않습니다. 운영자는 방문자의 이름, 이메일 주소, 연락처를 수집하거나 보관하지 않습니다.

2. 호스팅

사이트는 GitHub Pages에서 호스팅됩니다. 페이지 요청 과정에서 방문자의 IP 주소, User-Agent, 요청 URL 등이 GitHub, Inc. 의 서버 로그에 기록될 수 있으며, 이는 GitHub의 정책에 따라 처리됩니다. 운영자는 이 로그에 접근할 수 없습니다.

  • GitHub 개인정보처리방침

3. 광고 및 쿠키 (Google AdSense)

사이트는 Google AdSense를 통해 광고를 게재합니다.

  • 제3자 공급업체(Google 포함)는 쿠키를 사용하여 사용자가 이 사이트 또는 다른 사이트를 방문한 기록에 근거하여 광고를 게재합니다.
  • Google은 광고 쿠키를 사용해 사용자에게 개인 맞춤 광고를 표시합니다.
  • 사용자는 광고 설정에서 개인 맞춤 광고를 선택 해제할 수 있습니다. 또는 www.aboutads.info에서 제3자 공급업체의 쿠키 사용을 일괄 선택 해제할 수 있습니다.
  • Google의 광고 데이터 처리 방식은 Google 광고 및 쿠키 정책에서 확인할 수 있습니다.

브라우저 설정에서 쿠키를 차단할 수 있으며, 차단하더라도 사이트의 글 열람에는 지장이 없습니다.

4. 그 밖의 외부 리소스

페이지를 표시하는 과정에서 아래 외부 서비스로 리소스 요청이 발생하며, 이때 IP 주소와 User-Agent가 해당 사업자에게 전달됩니다.

5. 분석 도구

Google Analytics를 포함한 웹 분석 도구는 사용하지 않습니다.

6. 아동의 개인정보

사이트는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

7. 저작권 및 인용

각 논문 리뷰는 운영자가 원문을 읽고 직접 작성한 해설입니다. 인용된 그림과 표는 해당 논문의 저작권자에게 권리가 있으며, 출처를 명시해 비평·연구 목적으로 인용합니다. 게재를 원하지 않는 자료가 있다면 아래 연락처로 알려 주시면 즉시 삭제합니다.
